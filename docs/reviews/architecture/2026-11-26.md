### Tiiny AI Pocket Lab, detail

- What: 80 GB LPDDR5X (owner: split between CPU and NPU), 12-core ARM plus NPU (about 160-190 TOPS), about 30 W, about US$1,299-1,399 (early bird, Kickstarter March 2026). Runs its own converted models (owner: "dedicated models") behind an HTTP endpoint (gateway `/v1/chat/completions`, `/v1/embeddings`, `/v1/image/generate`, ...). OpenAI compatibility is not confirmed; no Ollama.
- Independent data: [TiinyBench](https://www.tiinybench.app/) (MIT, by Jason Brashear / Titanium Computing; one device, firmware 0.1.34; speed only, "no quality evaluation"; each model measured alone, the box queues one inference at a time): gemma-4-26B-A4B 21.7 tok/s (first token about 0.25 s); Qwen3-30B-A3B 29.3; gpt-oss-20b 30.9; gpt-oss-120b 18.8 (first token about 1.05 s); dense 27B about 6-13 tok/s.
- Earlier discussion 2026-11-25 (owner asked whether it helps local inference speed): not a speed fix for 12B-26B; useful as a dedicated box or for bigger models.
- Revisit when: an OpenAI-compatible endpoint NERV can call is confirmed (or an adapter exists); a Gauntlet campaign through that endpoint checks quality; the owner needs models over 36 GB; or Mac contention becomes a real problem. Compare then with: a Mac mini with more memory, AMD Ryzen AI Max (128 GB) mini PCs, NVIDIA DGX Spark (all Ollama-capable).
